# 交互式数据分析工作台

离线版交互式数据分析工具，涵盖多源接入、查询分析、可视化图表、报告生成、异常检测与数据服务编排，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：React + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/api/filter-service.ts  数据筛选引擎：规则版本、分块缓存、下钻、分片、结果导出
│   ├── src/domain/filter/    筛选领域模型：类型、校验、分块计算、持久化、导出格式
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── scripts/check-filter-engine.ts  筛选引擎行为自检
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 数据筛选引擎

数据筛选页（`/filter`）不只是登记规则，它带了一套可验证的筛选执行模型：

- **分块复用**：规则按「筛选字段 + 逻辑组合」划分块，块签名只由块内谓词决定。只改一个
  比较运算符时，只有签名变化的那块重新过滤，其余块直接复用分块缓存（缓存键含数据集
  结构版本与数据版本）。下钻页复用同一份分块结果与规则版本。
- **规则版本**：发布时生成不可变版本；相同筛选内容连续发布复用已有版本，不递增版本号。
  展示列调整不产生新版本。
- **下钻固定版本**：同一规则一次下钻后固定「首次引用版本」，之后规则再发布、停用都不会
  改写已有下钻结果。
- **停用语义**：停用后旧命中行仍保留溯源（版本、分块条件、行快照），但不再参与新输出。
  停用期间执行请求返回「规则未执行」，而不是「确实无命中」。
- **前置校验**：条件值缺失、正则无效、同一 AND 分块内等值类与区间类比较混用（以及区间
  上下界矛盾）都会在进入计算前被拒绝。
- **类型变化**：目标数据集字段结构变化后结构版本递增，旧候选集失效，不做隐式类型转换；
  受影响规则标记「需要重新校验」，重新启用会再次校验字段可用性。
- **分片任务**：每个分片任务启动时记录所读版本（同一规则两个分片各记各的）。批次执行期间
  规则被同步停用时，当前批次完整跑完才停止后续读取。
- **导出**：命中行可下载为结果文件，文件头与每行都标注规则版本；规则配置可打包归档为 JSON。

行为自检：

```bash
cd frontend
npm run check:filter
```

## 业务模块

| 模块 | 目录 | 业务对象 | 主要字段 |
| --- | --- | --- | --- |
| 交互查询 | `query` | 查询语句 | 语句编号、查询表达式、目标数据集 |
| 可视化图表 | `chart` | 图表配置 | 图表编号、图表名称、图表类型 |
| 数据源接入 | `source` | 接入配置 | 配置编号、连接类型、接入地址 |
| 聚合计算 | `aggregate` | 聚合方案 | 方案编号、聚合函数、目标字段 |
| 数据筛选 | `filter` | 筛选规则 | 规则编号、目标数据集、筛选字段 |
| 报告生成 | `reportgen` | 报告模板 | 模板编号、模板名称、包含图表 |
| 异常检测 | `anomaly` | 检测规则 | 规则编号、监控指标、基线均值 |
| 多维下钻 | `drill` | 下钻路径 | 路径编号、起点维度、下钻层数 |
| 对比分析 | `compare` | 对比方案 | 方案编号、基准数据集、对照数据集 |
| 分析流水线 | `pipeline` | 流水线节点 | 节点编号、节点类型、输入源 |
| 数据集管理 | `datastore` | 数据集定义 | 数据集编号、数据集名称、来源表名 |
| 趋势预测 | `forecast` | 预测模型 | 模型编号、模型类型、训练数据集 |
| 数据分片 | `segment` | 分片规则 | 规则编号、目标数据集、分片字段 |
| 调度管理 | `scheduler` | 调度配置 | 配置编号、关联任务、调度表达式 |
| 通知分发 | `notify` | 通知规则 | 规则编号、触发条件、通知渠道 |
| 查询缓存 | `cache` | 缓存策略 | 策略编号、目标查询、缓存键规则 |
| 数据标签 | `tag` | 标签定义 | 标签编号、标签名称、计算表达式 |
| 数据分享 | `share` | 分享链接 | 链接编号、目标数据集、访问密码 |

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `interactive-analytics-lab:entries` 这一项，或调用 `resetModule(模块)`。
